# 輪播貼文固定流程（日落占卜／課程介紹）

依「島主風格手冊」Carousel 版型：4:5（1080×1350）、一組 6 張、主題只有一個。

## 流程
1. **選題**
   - 日落占卜：從素材總表「熱門話題」挑島主勾「要」的一列（或「議題」分頁）。
   - 課程介紹：直接用官網 `index.html` 的 `EVENTS` 資料（時間、地點、費用以官網為準）。
2. **寫內容**：複製 `specs/` 裡同類型的範本，改成新的檔名，只改文字和圖。
   - 封面 `cover`：英文小標、主視覺（`kv/` 的圖）、直書標題、一句白話副標。
   - 內頁 `page`：英文小標＋主標＋2～3 句內文；可加「ISLAND WORDS」島主的話（`quote`）、說明小字（`small`）或一張小圖（`image`）。
   - 結尾 `end`：問句＋一個動作（CTA），自動放官方 LINE QR。
   - `post`：貼文標題、貼文文字、標籤、行動呼籲。
3. **出圖**：`node render.js specs/<檔名>.json <輸出資料夾>` → 01.png～06.png。
4. **交付**：上傳到雲端硬碟「PAUSE SPACE｜自媒體工廠／輪播成品」，在素材總表「產出紀錄」加一列（文案、標籤、檔案連結、待發佈）。

## 兩種內容的頁序
| 頁 | 日落占卜 | 課程介紹 |
|---|---|---|
| 01 | 封面：議題的白話版 | 封面：課名＋一句承諾 |
| 02 | THE QUESTION：這週的議題 | FOR YOU：適合誰 |
| 03 | CARD：抽到的牌 | 內容 1 |
| 04 | READING：牌想對你說 | 內容 2 |
| 05 | TRY THIS：今晚的小練習 | INFO：時間地點費用 |
| 06 | 結尾：私訊／官方 LINE | 結尾：報名 |

## 寫字規則
- 貼文是島主的聲音，用「你」；活動說明小字用「您」。
- 不寫療效、不保證結果；不蹭沒親自參加的展覽與娛樂新聞。
- 主視覺原圖左側有小字，封面用 `zoom`（例如 `"160% auto"`）＋`pos`（例如 `"100% 40%"`）裁掉。
